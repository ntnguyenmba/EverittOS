# EverittOS MVP

A polished Next.js web app MVP for a premium AI-powered field operations platform.

## Run in VS Code

1. Open the `everittos` folder in VS Code.
2. Open Terminal in VS Code.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open `http://localhost:3000` in your browser.

## Pages included

- Home
- Product
- Industries
- Pricing
- Demo
- Login
- Manager Dashboard
- Jobs
- Job Detail
- Workers
- Admin Settings
